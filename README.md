# 🚀 Prueba de GitHub Pages con Múltiples Archivos

Este repositorio es una prueba para verificar que GitHub Pages puede manejar múltiples archivos HTML, CSS y JavaScript sin afectar la estructura del repositorio.

## 📁 Estructura


```
mi-repo-prueba/
├── index.html          # Página principal
├── about.html          # Página "Acerca de"
├── contacto.html       # Página de contacto
├── css/
│   └── styles.css      # Estilos globales
├── js/
│   └── main.js         # JavaScript global
└── README.md           # Esta documentación
```

## ✅ Características probadas

- [x] Múltiples páginas HTML
- [x] CSS externo
- [x] JavaScript externo
- [x] Navegación entre páginas
- [x] Rutas relativas
- [x] Responsive design
- [x] Formulario simulado
- [x] Almacenamiento local (localStorage)
- [x] Sin dependencias externas

## 🌐 Cómo desplegar

1. Clona este repositorio
2. Ve a **Settings > Pages**
3. Selecciona la rama `main` y guarda
4. Tu sitio estará disponible en: `https://[usuario].github.io/[repo]`

## 📝 Notas

- Todos los archivos están en la raíz del repositorio
- Las rutas son relativas para mantener la compatibilidad
- No se necesita ningún build tool o dependencia
